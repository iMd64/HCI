★ High-Yield HCI Laws & Exam Formulas

Core mathematical formulas and psychological thresholds repeatedly tested on COM481 exams.

Must Know!
Fitts's Law (Movement Time) Week 3
T = a + b · log₂( 2D / W )

Fast targets are big and close. Screen edges act as infinite width targets (W = ∞), dropping Index of Difficulty to zero!

Working Memory Capacity Week 2
Cowan: 4 ± 1 Chunks (20–30s)

Miller's 7±2 applies to digits; for complex UI tasks, memory holds only 4±1 chunks. Always externalize state on screen!

Psychological Time Thresholds Week 3
0.1s (Causality) • 1.0s • 10.0s

Delay > 100ms breaks feeling of direct causality. "When the interface stays silent, users act twice."

Norman's Triad of Models Week 2 & 5
Design Model → System Image → User Model

Designer cannot talk to user directly. If the System Image is flawed or ambiguous, user's mental model will be broken.

Heuristic Evaluator Curve Week 5
3 to 5 Evaluators = 75%–85% Usability Bugs

Single evaluator finds only ~35%. 5 evaluators provide optimal cost-benefit before diminishing returns set in.

ISO 9241-210 UCD Cycle Week 6
Context → Reqs → Design → Evaluate

Iteration is not a failure of planning; it is the fundamental mechanism of User-Centered Design.
